Privacy Policy

VxD Broadcast Relay

An internal broadcast tool. It starts and ends live video on two Facebook Pages we own, and handles no data about anybody else.

Last updated 16 September 2026 · Facebook App ID 28453934654262266

The short version. This application has exactly one user: the operator who runs it. It stores one credential — a Facebook Page access token — so it can create and end live broadcasts. It collects nothing about viewers, uses no cookies or analytics, and shares nothing with anyone.

Who operates this application

VxD Broadcast Relay is built and operated by VxD Media, Malé, Republic of Maldives, publisher of the news outlets VOICE (voice.mv) and DHUVAS (dhuvas.mv). The application runs on our own infrastructure at mix.vxd.news and is not distributed to, installed by, or offered to anyone else.

What the application does

It automates live broadcasting for our own events. When an operator starts an event, the application creates a live video on our Facebook Pages, passes the resulting stream keys to our encoder, and publishes the broadcast once the encoder confirms it is running. When the event ends, it closes those broadcasts.

What data it accesses

Page identity The name and numeric ID of the Facebook Pages we own, used to address the right Page and to confirm the connection is healthy before an event.
Page access token A long-lived credential that authorises the application to act for our Pages. Stored as an environment variable on our server and never displayed, logged, or transmitted anywhere except to Facebook.
Live video objects The broadcasts the application itself creates — identifier, title, description, status, and stream URL — held only for the duration of an event so it can publish and later end them.

The permissions requested are pages_show_list, pages_read_engagement, pages_manage_posts and publish_video. Each is required for the function above; none is used for any other purpose.

What it does not access

  • No personal information about viewers, followers, or commenters.
  • No messages, comments, or reactions.
  • No advertising, audience, or insights data.
  • No Pages other than those belonging to us.
  • No cookies, trackers, analytics, or advertising identifiers of any kind.

How the data is stored and protected

The Page access token is held as an environment variable on our hosting provider and is available only to the running application. It is not written to a database, not committed to source control, and not included in logs. Traffic between the application and Facebook uses HTTPS. The application's own control interface is reachable only over HTTPS.

Broadcast identifiers exist in the application's memory for the length of an event and are discarded when the event ends or the service restarts.

Sharing

We do not sell, rent, or share any data with third parties. The only external service the application communicates with is the Facebook Graph API, in order to perform the broadcasting described above.

Retention

The access token is retained until it is revoked or replaced. Broadcast identifiers are not retained beyond the event. Because no personal data of any other person is collected, there is nothing else to retain.

Your rights and how to exercise them

If you believe this application holds data relating to you, or you administer a Page you think it has access to, you can ask us to remove that access and delete anything associated with it. See Data Deletion Instructions for exactly how, or write to us at the address below. We respond within 30 days.

Children

The application is an internal broadcasting tool with no public sign-up and no users other than our own staff. It is not directed at children and collects no information from them.
